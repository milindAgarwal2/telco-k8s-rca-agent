# AIDE regression evaluation workflow

Follow `.aide/workflows/definitions/evaluate-aide.md`. Keep tasks, repository revisions, model/tool settings, acceptance criteria, and held-out tests fixed. Report correctness, unintended changes, human corrections, verification completeness, time, cost, and failures. Do not alter evaluated work or tests to improve the score.
