# Skill creator specification

## Intent

Create focused Kiro skills with reliable activation, progressive instructions,
safe boundaries, and measurable evaluation cases.

## Contract

Each skill has valid name and description frontmatter, activation and near-miss
examples, explicit outputs and stop conditions, and only justified supporting
resources.

## Failure handling

Overlapping scope, invalid metadata, unresolved dependencies, or unsafe implied
authority blocks installation and is reported for revision.
