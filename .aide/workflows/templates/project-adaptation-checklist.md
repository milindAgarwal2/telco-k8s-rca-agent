# Project Adaptation Checklist

- [ ] Select and record an immutable repository revision.
- [ ] Classify repository languages, artifacts, build tools, and runtime type.
- [ ] Locate existing instructions, specifications, tests, and knowledge.
- [ ] Review every validation command before authorizing execution.
- [ ] Define protected files, environments, and sensitive-data boundaries.
- [ ] Define source/specification/knowledge authority and conflict handling.
- [ ] Name specification, change, knowledge, operations, merge, and deployment
      decision owners.
- [ ] Map installed AIDE agents and skills to the catalogue requirements.
- [ ] Review MCP servers individually and keep diagnostic access read-only.
- [ ] Validate hooks against the installed Kiro client before relying on them.
- [ ] Run the structural workflow-package validation.
- [ ] Trial one workflow in a disposable branch or lab target under supervision.
- [ ] Record limitations and any project-specific workflow extension.
- [ ] Confirm generated artifacts remain drafts until the named review.
