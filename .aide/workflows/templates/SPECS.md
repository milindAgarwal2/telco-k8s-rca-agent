# Workflow Template Specifications

## Intent

This folder contains project-neutral Markdown shapes used to adapt workflows
and record a run consistently across repositories.

## Inputs and outputs

Templates accept reviewed project facts, selected revisions, gate decisions,
and reproducible evidence. Completed copies are outputs of a workflow run; the
templates themselves are never evidence that an action occurred.

## Contract

Placeholders must be replaced or explicitly marked `Not applicable` or
`Unresolved`. A blank field must not be interpreted as approval.

## Interactions

Workflow definitions name the template appropriate to each phase. Projects may
extend templates, but must preserve fact/inference separation and human gates.
